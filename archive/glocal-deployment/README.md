# Retired Glocal deployment

These files preserve the previous standalone KnowledgeHub/Glocal deployment. Scripts exit before any action and configuration examples contain placeholders. The ignored local `knowledgehub-client/deploy/` files were captured explicitly. Historical documents are references only; passwords and tokens have been redacted.

Use the repository root `.env.production`, `scripts/remote-deploy.sh`, and [the active deployment guide](../../docs/server/DOCKER-AND-DEPLOYMENT-GUIDE.md). Do not use `/www/knowledgehub-deploy` for new releases. The original Git history remains reachable through the unsquashed subtree import.
