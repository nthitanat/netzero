# Retire NetZero architecture skill adoption

**Date:** 2026-09-30 Asia/Bangkok
**Authorization:** User requested removal of the repository skill folder and use of the guide in `docs/` only.

NetZero no longer adopts a `general-architecture` skill revision. `docs/GENERAL_ARCHITECTURE.md` owns project architecture guidance, and `AGENTS.md` routes architecture work there. The Docker guide continues to own deployment procedures. This supersedes the NetZero adoption recorded on 2026-09-29; those records remain historical.

The change does not alter installed copies in Codex homes or other projects' adoption decisions. [Removal result](../code-changes/2026-09-30-retire-general-architecture-skill.md).
