# Glocal course route in NetZero

**Status:** Complete

## Scope

Add a public `/courses` client route and navigation item in NetZero. The route takes users to the existing Glocal course catalog at the deployed `/glocal/#/courses` path. The Glocal application remains the owner of course content and detail pages.

## Steps

1. Added the NetZero route, page, navigation item, and course icon.
2. Built the client successfully and checked the catalog destination against the Glocal deployment path in the repository.
3. Recorded tested results and limits in the code-change log.

This task does not add a new course backend, copy Glocal course data into NetZero, or deploy either app.
